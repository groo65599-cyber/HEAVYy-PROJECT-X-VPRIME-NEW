Safe Android launcher/dashboard prototype.

## Roles
- FREE: Power-limited launcher; no Grafik MC access.
- PREMIUM: Unlimited Power.
- RESELLER: Unlimited Power + can create Premium accounts.
- PRESS: Unlimited Power and expanded access in the prototype.
- DEVELOPER: Full prototype access and can create Developer #2, Reseller, and Premium accounts.

## Power
- FREE starts with 100 Power.
- Run Free Fire / Free Fire MAX consumes 100 Power when no active one-hour run window exists.
- Add Power grants 100 Power after a 20-second cooldown.
- Maximum stored Power: 700.
- Premium/Reseller/Press/Developer have unlimited Power.

This prototype only launches installed apps and reads Android device metrics. It does not inject, modify, automate, or bypass game/anti-cheat processes.


## Clear Cache UI
PRESS and DEVELOPER roles get a Clear Cache FF / FF MAX menu. The app shows a HEAVYy PROJECT X progress overlay and then opens Android's App Info page for the selected game. The user must perform the actual Clear Cache action in Android; the overlay never claims that cache was cleared automatically.

## Animated loading sequence
- The startup now plays a five-frame cinematic sequence based on the reference images supplied for this project.
- Frames are cropped from the supplied reference screenshots so YouTube black bars are not included.
- Each frame uses a short fade/zoom transition, followed by the Username/Password screen.
- The final frame is the monochrome sword reference used as the closing visual before login.

The launcher checks known Free Fire / Free Fire MAX package IDs and declares them in Android package-visibility queries.

The sequence is purely visual UI; it does not inject, modify, automate, or bypass game/anti-cheat processes.
